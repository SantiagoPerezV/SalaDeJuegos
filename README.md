# SalaDeJuegos
Proyecto completo de una sala de juegos. Hecho con Angular.

Incluye consumo de API's, Chat en tiempo real, Login y Registro de usuarios, lógica de juegos, animaciones con GSAP, guardado de Score según usuario

## Tecnologías
🔸 Angular, HTML, CSS, Gsap

🔸 Base de datos: Supabase
